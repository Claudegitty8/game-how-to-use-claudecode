# Glossar: Begriffe des Projekts

Dieses Glossar erklärt die Wörter, die wir **beim Bauen** des Spiels verwenden. Die KI-Fachbegriffe, die das Spiel lehrt, stehen in `LEHRPLAN.md` und später im Lexikon des Spiels.

## Spiel

| Begriff | Bedeutung |
|---|---|
| **Kiwi** | Die KI-Figur im Spiel. |
| **Kapitel** | Eine Ausbaustufe des Studios mit einem Thema. Es gibt sechs. |
| **Auftrag** | Ein Kunde mit einem Wunsch. Besteht aus mehreren Runden. |
| **Runde** | 5 bis 10 Minuten. Führt genau ein neues Kernkonzept ein. |
| **Fünf Schritte** | Probieren, Aha, Beispiel, Lücke, Frei. |
| **Situation** | Eine einzelne Aufgabe innerhalb des Schritts «Frei». |
| **Mischrunde** | Letzte Runde eines Auftrags, kombiniert alte und neue Konzepte. |
| **Kernkonzept** | Eines der 24 Konzepte, die nach der Meisterschaftsregel geübt werden. |
| **Lexikon-Begriff** | Ein Begriff, der erklärt, aber nicht abgeprüft wird. |
| **Meisterschaft** | Drei Erfolge ohne Hilfe in drei verschiedenen Situationen. |
| **Werkstatt** | Der Bildschirm, auf dem man Bausteine wählt und verdrahtet. |
| **Baustein** | Ein sichtbares Teil in der Werkstatt, z. B. Prompt oder Tool. |
| **Zutat** | Ein Textteil oder Baustein, den eine Aufgabe braucht oder anbietet. |
| **KI-Quatsch** | Kiwis lustiges, aber logisches Fehlresultat. |
| **Fehlbild** | Ein vorbereiteter KI-Quatsch für eine bestimmte fehlende Zutat. |
| **Hinweis** | Der Satz, der erklärt, warum der Quatsch passiert ist. |
| **Schnelltest** | Abkürzung für Leute mit Vorwissen. |
| **Simulierter Modus** | Kiwi antwortet nach festen Regeln, ohne echte KI. |
| **Echt-Modus** | Freiwilliger Zusatz für Erwachsene mit echter Claude-Anbindung. |

## Technik

| Begriff | Bedeutung |
|---|---|
| **Repository** | Der Projektordner auf GitHub mit seiner ganzen Geschichte. |
| **Commit** | Ein Speicherpunkt mit kurzer Beschreibung. |
| **main** | Der Hauptstand des Projekts. |
| **Spiellogik** | Die Regeln des Spiels als Code, ohne Oberfläche. |
| **Oberfläche** | Alles, was man sieht und antippt. |
| **Lerninhalte** | Aufträge, Texte, Fehlbilder und Lexikon als Daten. |
| **JSON** | Ein einfaches Textformat für Daten. |
| **Test** | Ein kleines Programm, das prüft, ob der Code tut, was er soll. |
| **Inhaltsprüfung** | Programm, das die Lerninhalte auf Vollständigkeit prüft. |
| **Web-App** | Eine Anwendung, die im Browser läuft. |
| **Service Worker** | Technik, mit der eine Web-App ohne Internet läuft. |
| **Vorschau-Seite** | Private Seite mit Link, auf der der aktuelle Stand spielbar ist. |
